Arduino

Arduino es una plataforma electrónica que permite crear diferentes proyectos utilizando una placa programable. Para programarla se utiliza un lenguaje basado principalmente en C y C++.

La placa

La placa Arduino contiene un microcontrolador que se puede programar para recibir información y controlar diferentes componentes electrónicos.

Programación

El programa se escribe en la computadora y luego se carga en la placa. A partir de las instrucciones recibidas, Arduino puede controlar luces, motores, sensores y otros componentes.

Usos

Arduino se utiliza para aprender programación y electrónica, crear robots, sistemas automáticos, alarmas, controles de luces y muchos otros proyectos.
