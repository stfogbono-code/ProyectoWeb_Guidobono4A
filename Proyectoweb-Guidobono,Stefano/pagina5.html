PHP

PHP es un lenguaje de programación utilizado principalmente para el desarrollo de páginas y aplicaciones web. El código se ejecuta en el servidor y permite generar contenido que luego es enviado al navegador.

Historia

PHP fue creado por Rasmus Lerdorf en 1995. Al principio fue pensado como una herramienta sencilla para trabajar con páginas web, pero con el tiempo fue creciendo hasta convertirse en un lenguaje muy utilizado.

Funcionamiento

PHP trabaja del lado del servidor. Cuando una persona entra a una página, el servidor ejecuta el código PHP y envía al navegador el resultado que debe mostrarse.

Usos

Se utiliza para trabajar con formularios, usuarios, contraseñas, bases de datos y diferentes tipos de información. También permite crear páginas que cambian según los datos ingresados por cada usuario.
